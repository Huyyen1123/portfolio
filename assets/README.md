# Assets

- **images/** — empty. Add `background.png` (your Minecraft panorama screenshot, 1920×1080 or larger) and the landing page's `.ts-bg` layer picks it up automatically — no code change needed. Until then, `.ts-bg` falls back to a plain dark `background-color`, silently (no placeholder graphic or instructional text on the page itself). The title logo and player sprite are still built from SVG/CSS rather than raster images, so no placeholder files exist for those.
- **fonts/** — `Minecraft.otf` / `Minecraft-Bold.otf`, the pixel display font used throughout the UI ("Minecraft" by Idrees Hassan, [github.com/IdreesInc/Minecraft-Font](https://github.com/IdreesInc/Minecraft-Font), SIL Open Font License 1.1 — see `LICENSE-Minecraft-Font.txt` here, retained per the OFL's terms). Press Start 2P (Google Fonts, also OFL) is the fallback if the local file fails to load. The body font (IBM Plex Mono) is still loaded from Google Fonts via `<link>` in `index.html`.
- **sounds/** — empty; hover/click UI sounds are synthesized at runtime with the Web Audio API (see `js/main.js`), not bundled audio files, to avoid relying on de-facto "royalty-free" files with unverified licensing. Background music is wired up (Settings → Music) but has no track — drop an audio file here, point `#bg-music`'s `src` at it in `index.html`, and it'll play/pause/loop through the existing toggle.
